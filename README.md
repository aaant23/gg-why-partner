# gg-why-partner
"Why partner with us?" page for The Green Group

Based on one page of a proposal document I produced while working at the company, this code was written one afternoon to demonstrate how the document could be adapted for use as a landing page on the company website.

It was also intended to showcase a suggested visual refresh for the overall site.

Further developments would include Google Maps integration and links to the companies' dedicated service pages, as well as information on the company's sustainability goals and product offering.

[See live Github site](https://aaant23.github.io/gg-why-partner/)
